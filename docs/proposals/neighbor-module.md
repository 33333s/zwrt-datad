## 目标

将现有 U60 邻小区功能整合进 zwrt-datad。

由 datad 管理采集、解析、缓存和运行状态，
不再依赖独立 UFI 邻小区插件及其 HTTP API。

## 拟引入的代码

- 邻小区 C 解析器。
- 现有各固件版本的日志格式识别与解析逻辑。
- DIAG 采集生命周期管理。
- 结果缓存、过期判断及异常恢复逻辑。

仅引入必要源码与脱敏测试样本，
不提交设备凭据、完整采集日志或研究目录。

## 工程结构

拟新增：

- include/neighbor.h：邻区模块公共定义。
- src/neighbor/：解析器、固件适配及结果规范化。
- src/neighbor_manager.c：采集、调度和工作进程管理。
- tests/neighbor/：各固件样本与回归测试。

同时更新构建脚本、配置说明和状态字段文档。

## 运行方式

- 邻区模块默认关闭，通过明确配置启用。
- datad 负责启停和管理所属工作进程。
- 耗时采集与解析在独立工作进程运行，
  不阻塞 datad 主循环。
- 保证单实例，识别已有 DIAG 占用。
- 停止时只清理本模块所属进程及临时数据。
- 日志与采集缓存设置容量上限。

使用设备现有 diag_mdlog；
缺少依赖时明确报告，不自动下载或冒充启动成功。

由屏幕和 UFI 使用。

- 暂无报告、空结果、数据过期及采集故障。
