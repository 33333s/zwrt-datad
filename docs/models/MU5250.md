# MU5250 API Template

模板 ID：`MU5250`

匹配规则：

- `device.model_name == "MU5250"`
- 或 `device.hardware_version` 以 `MU5250_` 开头

这个模板代表当前后端正式支持的 `U60 Pro` 设备侧接口集合。它的目标是把 `U60` 自己的接口固定下来，不再把其他机型的回退逻辑默认混进主路径。

## Device-Side Interfaces

`ubus`：

- `zte_nwinfo_api nwinfo_get_netinfo`
- `zwrt_bsp.battery list`
- `zwrt_bsp.charger list`
- `zwrt_bsp.thermal get_cpu_temp`
- `zwrt_router.api router_get_user_list_num`
- `zwrt_router.api router_get_status_no_auth`
- `zwrt_data get_wwandst`
- `zwrt_data get_wwaniface`
- `zwrt_data get_wwandst_monthlimit`
- `zwrt_data get_wwandst_clearday`
- `zwrt_zte_mdm.api get_sim_info`
- `network.interface.lan status`
- `network.interface.zte_wan status`
- `network.interface.zte_wan6 status`
- `zwrt_router.api router_get_lan_info`
- `zwrt_zte_mdm.api get_zwrt_common_info`
- `zwrt_zte_mdm.api get_imei`
- `zwrt_bsp.usb list`
- `zwrt_nfc zwrt_nfc_wifi_get`
- `zwrt_wms zwrt_wms_get_wms_capacity`
- `zwrt_wms zte_libwms_get_sms_data`
- `system info`
- `system board`

与其他当前模板一致，MU5250 默认启用 `GET /ubus`、`GET /ubus?verbose=1`
和 `POST /ubus/call`。完整调用入口覆盖设备运行时注册的所有 ubus 对象和方法，
包括写方法；本机监听免鉴权，LAN 监听仍要求现有 Bearer Token 鉴权。

`uci`：

- `wireless.main_2g.ssid`
- `wireless.main_2g.key`
- `wireless.main_2g.encryption`
- `wireless.main_2g.disabled`
- `network.lan.ipaddr`
- `dhcp.lan.start`
- `dhcp.lan.limit`
- `dhcp.lan.leasetime`

文件 / sysfs：

- `/tmp/dhcp.leases`
- `/data/logfs/key.log`
- `/proc/stat`
- `/proc/meminfo`
- `/proc/net/{tcp,tcp6,udp,udp6,unix}`
- `/sys/devices/system/cpu/cpu*/cpufreq/*`
- `/sys/class/thermal/thermal_zone*/{type,temp}`
- `/sys/class/power_supply/usb/voltage_now`
- `/sys/class/power_supply/usb/current_now`
- `/sys/class/power_supply/battery/voltage_now`
- `/sys/class/power_supply/battery/current_now`

## Observed Notes

- 已在固件 `BD_CNMU5250V1.0.0B31`、OpenWrt 23.05.4、SDX75/aarch64
  实机验证模板识别、状态采集和完整 ubus 传输。
- 实机注册 135 个 ubus 对象；`ubus -v list` 为 64,591 字节，完整落在
  datad 的 128 KiB catalog 缓冲区内。
- 实机 `main_2g` 与 `main_5g` 均存在且启用；统一状态中的单一 `wlan` 记录仍按
  本模板约定展示 `main_2g`，完整双频配置可通过 `/ubus/call` 或控制接口访问。
- 实机 `zwrt_bsp.thermal get_cpu_temp` 返回有效 `cpuss_temp`，主数据接口为
  `rmnet_data0`，`network.interface.zte_wan/zte_wan6` 均可正常读取。
- 实机 DHCP lease 数与路由在线客户端计数一致，当前无需启用路由访问列表回退。

## Explicit Non-Goals

这个模板当前故意不启用下面这些“宽松兼容”来源：

- `zwrt_bsp.thermal list`
- `thermal_zone` sysfs CPU 温度回退
- `wireless.main_5g` 自动选主 Wi-Fi
- `zwrt_router.api router_lan_access_list`
- `zwrt_router.api router_wireless_access_list`

这些路径后续如果要服务其他机型，会放进对应机型模板里单独维护，而不是继续混在 `U60` 模板主路径里。
