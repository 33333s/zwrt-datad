# MC7523 API Template

模板 ID：`MC7523`

匹配规则：

- `device.model_name == "MC7523"`
- 或 `device.hardware_version` 以 `MC7523` 开头

当前对应实机：

- 展示名称：`G5 Max WiFi`
- `device.hardware_version = "MC7523HW1.0"`
- 固件：`BD_ZXSTCNMC7523V1.0.0B05`
- 平台：Qualcomm SDX75 / aarch64 / OpenWrt 23.05.4

MC7523 是单基带设备。状态采集沿用单主 PDN 的 `cid=1` 路径，不启用 MU5252 的三个 modem、外挂基带或活动 `subid` 逻辑。

MC7523 / G5 Max WiFi 是无电池 CPE。实机 `zwrt_bsp.battery list` 仍会返回全 0 占位值，模板必须忽略该伪接口，因此 `/state` 不输出 `battery`。设备提供 2.4G/5G Wi-Fi，未注册 `zwrt_nfc`，所以模板按实际接口输出 `wlan`、省略 `nfc`。

## Device-Side Interfaces

状态模板使用：

- `zte_nwinfo_api nwinfo_get_netinfo`
- `zwrt_data get_wwaniface/get_wwandst/get_wwandst_monthlimit/get_wwandst_clearday`
- `zwrt_zte_mdm.api get_sim_info/get_zwrt_common_info/get_imei`
- `network.interface.lan/zte_wan/zte_wan6 status`
- `zwrt_router.api router_get_user_list_num/router_get_status_no_auth/router_get_lan_info`
- `zwrt_router.api router_lan_access_list/router_wireless_access_list`
- `zwrt_bsp.thermal/usb`（battery/charger 的全 0 占位不作为有效电池）
- `zwrt_wms` 短信容量和列表接口
- `system info/board`
- `uci` 的 Wi-Fi、LAN 和 DHCP 配置

与所有当前模板一样，MC7523 默认启用 `GET /ubus`、`GET /ubus?verbose=1` 和 `POST /ubus/call`。完整调用入口可以访问运行时注册的全部 ubus 方法，包括写操作和可能导致设备重启、断网或配置变化的方法；调用方必须自行约束。

## Field Mapping

- `net.*`：`zte_nwinfo_api nwinfo_get_netinfo`
- `traffic.*`：`zwrt_data get_wwandst {"source_module":"deviceui","cid":1,"type":1}`
- `interfaces.wan4/wan6`：`network.interface.zte_wan/zte_wan6 status`
- `sim.*`：`zwrt_zte_mdm.api get_sim_info`
- `wlan.*`：自动选择 `wireless.main_2g/main_5g` 主配置
- `clients.list`：以无线/有线路由访问列表为在线依据，DHCP 租约仅补全元数据
- `system.cpu_temp`：优先 thermal ubus，缺少有效值时回退 CPU thermal zone
- `thermal.cpu_celsius`：模板 CPU 温度，单位为摄氏度
- `thermal.zones[]`：直接读取 `/sys/class/thermal/thermal_zone*/{type,temp}`，过滤无效或不可读 zone，并规范化为排序后的 `{name,celsius}`
- `modems`：固定为空数组；MC7523 不使用 MU5252 多基带规范化结构
- `net.*_supported_bands`：每轮直接读取 `nwinfo_get_netinfo` 的 `lte_band`、`nr5g_sa_band_lock`、`nr5g_nsa_band_lock`，供前端实时生成锁频候选
- `runtime.storage`：固定统计 `/data` 文件系统，不使用只读根文件系统 `/`

## Compatibility Notes

- 主数据接口为 `rmnet_data0`，网络对象为 `zte_wan` 和 `zte_wan6`。
- 设备没有 NFC 和有效电池接口，模板省略对应状态块。
- CPU 温度优先使用 `cpuss_temp`，并保留会过滤无效值的 sysfs 回退。
