# MC8532B API Template

模板 ID：`MC8532B`

匹配规则：

- `device.model_name == "MC8532B"`
- 或 `device.hardware_version` 以 `MC8532B` 开头

当前对应实机：

- 展示名称：`G5 Pro`
- `device_alias_name = "G5 Pro"`
- `device.hardware_version = "MC8532BHW1.0"`

这个模板代表当前后端正式支持的 `G5 Pro` 设备侧接口集合。它与 `MU5250` 的主要差异不在网络和基础识别，而在温度、客户端列表和 Wi-Fi 取数策略上：

- Wi-Fi 主配置继续沿用 `main_2g/main_5g` 自动选择逻辑
- 客户端列表以无线/有线路由访问列表为在线依据，DHCP 租约仅补全元数据
- CPU 温度不再依赖 `zwrt_bsp.thermal get_cpu_temp`，而是允许回退到 `thermal_zone` 的 `cpuss-*` sysfs

## Field Mapping

| snapshot | source |
|----------|--------|
| `net.*` | 优先 `zte_nwinfo_api nwinfo_get_netinfo`；调用失败时回退选定的 `zte_nwinfo` UCI 缓存字段 |
| `net.lte_pci/lte_cell_id/lte_channel` | ubus 的 `lte_pci/cell_id/wan_active_channel`，UCI 回退路径同名 |
| `net.nrca` / `net.lteca` | `zte_nwinfo_api nwinfo_get_netinfo`（载波聚合描述符，原样透传） |
| `net.wan_status` | `zwrt_router.api router_get_status_no_auth` |
| `wlan.ssid/key/enc` | `wireless.main_2g/main_5g` 自动选择：优先启用中的主 Wi-Fi，回退到第一个存在的主 Wi-Fi |
| `wlan.enabled` | 对应主 Wi-Fi 的 `disabled` 取反 |
| `battery.*` | `zwrt_bsp.battery list` |
| `battery.charging/charger_*` | `zwrt_bsp.charger list` |
| `battery.chg_uv/chg_ua` | `/sys/class/power_supply/usb/voltage_now`、`current_now` |
| `battery.bat_uv/bat_ua` | `/sys/class/power_supply/battery/voltage_now`、`current_now` |
| `clients.total/wifi/lan` | `zwrt_router.api router_get_user_list_num` |
| `clients.list` | `router_wireless_access_list` + `router_lan_access_list`；DHCP 租约仅补全元数据 |
| `sms.unread` | `zwrt_wms_get_wms_capacity` 的 `sms_dev_unread_num + sms_sim_unread_num` |
| `sms.list` | `zte_libwms_get_sms_data {page:0,data_per_page:32,mem_store:1,tags:10,order_by:"order by id desc"}` |
| `nfc.switch` | `zwrt_nfc zwrt_nfc_wifi_get` |
| `traffic.*` | `zwrt_data get_wwandst {"source_module":"deviceui","cid":1,"type":1}` |
| `traffic.day/month/total/limit/clear_day` | `zwrt_data get_wwandst/get_wwandst_monthlimit/get_wwandst_clearday` |
| `sim.*` | `zwrt_zte_mdm.api get_sim_info` |
| `interfaces.*` | `network.interface.* status`、`router_get_lan_info`、`get_wwaniface` |
| `qos.usb_mode` | `zwrt_bsp.usb list` |
| `qos.qci` / `qos.ambr_*` | 启动时全量扫描 `/data/logfs/key.log` 的 QoS `[DATA]` 日志并缓存 |
| `dhcp.*` | `uci`：`network.lan.ipaddr`、`dhcp.lan.start/limit/leasetime` |
| `system.uptime/mem_*` | `system info` |
| `system.cpu_usage` | `/proc/stat` |
| `runtime.*` | `/proc/stat`、CPU cpufreq、thermal zones、`/proc/meminfo`、`statvfs("/data")`、`/proc/net/*`、网卡计数器 |
| `system.cpu_temp` | 先试 `zwrt_bsp.thermal` JSON 字段；无有效温度时回退 `thermal_zone` 的 `cpuss-*` / `cpu*` /最高有效温度 |
| `thermal.cpu_celsius` | 模板 CPU 温度，当前由 sysfs `cpuss-*` 回退计算，单位为摄氏度 |
| `thermal.zones[]` | `/sys/class/thermal/thermal_zone*/{type,temp}`，过滤无效或不可读 zone，并规范化为排序后的 `{name,celsius}` |
| `system.model/hostname/fw` | `system board` |
| `system.sw_version` | `zwrt_zte_mdm.api get_zwrt_common_info` 的 `wa_inner_version`，缺失时回退 `integrate_version` |
| `system.imei` | `zwrt_zte_mdm.api get_imei` |
| `device.model_name/hardware_version/alias_name` | `zwrt_zte_mdm.api get_zwrt_common_info` |
| `device.board_name` | `system board` |
| `device.profile` | 基于 `device.model_name` 规范化生成 |
| `device.api_template` | 后端模板选择结果，当前固定为 `MC8532B` |
| `uci_device_info.radio_*` | 选定的只读 `zte_nwinfo` UCI 缓存；不开放任意 UCI 透传，也不包含 Wi-Fi/APN 密码 |

## Compatibility Notes

- `device_market_name` 可能缺失，模板识别使用 `model_name`。
- CPU 温度正式使用 sysfs thermal zone 回退；无效、不可读和哨兵温度会被过滤。
- 本模板只定义 datad 后端适配，不包含设备端屏幕界面。
