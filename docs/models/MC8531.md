# MC8531 API Template

模板 ID：`MC8531`

匹配规则：

- `device.model_name == "MC8531"`
- 或 `device.hardware_version` 以 `MC8531` 开头

当前对应实机：

- 展示名称：`G5 Ultra`
- `device_alias_name = "G5 Ultra"`
- `device.hardware_version = "MC8531HW1.0"`
- 板型 `ap-sdxpinn-qcn9224`，固件 OpenWrt 22.03.5，aarch64

这个模板与 [`MC8532B`](MC8532B.md) 使用同一套设备侧接口和取数策略（只读核对：`zte_nwinfo_api`、`zwrt_bsp.*`、`zwrt_router.api`、`zwrt_data`、`zwrt_zte_mdm.api` 对象均存在，4 个 `cpuss` thermal zone 可读），差异只在识别信息：

- 没有电池：`zwrt_bsp.battery list` 返回 `battery_online:0` 占位值，不输出 `battery` 块
- 单基带、单 SIM 槽（`sim.dual_sim = 0`），与 MC8532B 一致
- 不使用 MU5252 的多基带/多 WAN 聚合路径

其余接口清单、Wi-Fi 取数和客户端列表策略见 MC8532B 文档。
